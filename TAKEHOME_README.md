# Supply Chain Optimization

## Background

We have taken pre-orders for our amazing new ARC hardware product, the first batches have been produced and customized for the customers and we are now ready to start shipping. From our factory in postcode DE 32756 we want to send them out so that customers with our own 10 autonomous delivery drones. Each drone can carry 200 ARCs. Assume that the drones have an average speed of 100km/h and practically unlimited range.

## Your mission

Complete the following tasks, making sure to adhere to the allocated time per task. 

### Task A - 60 minutes

The CEO wants maximum transparency and a portal where she can continously check when a certain order is planned to go out and be delivered. Build a prototype portal using the order data provided. Assume that the orders are delivered three working days after they are ready to ship.

### Task B - 15 minutes

We promise our customers to deliver within 5 days of being ready to ship. Describe how you would implement an algorithm to maximise the number of orders which meet this promise. No implementation required, a description of the summary (or pseudocode) is sufficient.

### Task C - 15 minutes

Create a plan/diagram/sketch describing the infrastructure that you would use to host the web portal. You can choose to keep it generic or tailor it to a cloud provider of your choice.
